# 输入配对与 FlexiKey 响应验证

## 已复现的缺陷

删除或切换绑定时，旧实现清空按下记录。最初被吞掉的按下，其后续重复事件可能传给 Windows，释放却再次被吞掉。录制触发键时也存在重复按下与释放不配对的路径。回归用例在原实现上失败，记录位于本机 target/validation/input-routing/baseline-regression.log。

原 FlexiKey 界面回调直接更新钩子并保存 XML。钩子命令确认最多等待 3 秒，文件系统操作也在界面线程执行；切换配置成功后还会再次更新输入引擎。

## 当前实现

- input_bindings.rs 统一管理键盘、鼠标和录制状态。一次物理按下确定该组重复、释放事件的归属；更换绑定、取消或重新录制保留该归属。必要的钩子持续到待配对释放处理完毕。
- 新启用钩子在处理消息前登记已经按住的物理键，避免接管其后续重复和释放。
- input_hooks.rs 先准备新增句柄，再修改已有句柄。新增设备失败保留原有钩子；命令传输失败或超时才进入线程停止路径。
- flexikey_jobs.rs 使用一个常驻配置线程和容量 32 的队列，串行执行运行时配置、写盘和回滚。输入回调使用非阻塞通知；界面回调提交完整草稿后立即返回。
- 结果携带请求编号。旧请求的完成结果不会覆盖较新的界面草稿；最新请求失败时恢复工作线程保存的最后一次成功状态。写盘失败和运行时恢复失败分别报告。
- 录制请求有独立代次。关闭编辑器、取消或重新开始录制，会使排队中的旧请求失效；配置过程中发生取消，也会在完成后撤销旧录制。
- flexikey_store.rs 集中处理 XML 与文件替换。界面文件负责草稿、校验和展示。

## 验证结果

- 主机测试 87 项通过；Windows 原生测试 90 项通过。
- Windows 全目标、全 feature 严格 Clippy 通过；应用与协议的既有边界统计保持 102。
- 输入路由 11 项测试覆盖长按、释放、设备隔离、预先按住的键、绑定变化、取消与重新录制；其中枚举深度为 6 的事件和配置交错。
- 队列测试覆盖阻塞配置下继续提交与取消、容量耗尽、旧完成结果、连续草稿、中间写盘失败、运行时回滚失败及录制取消竞争。
- Windows Release 的 --input-hooks-smoke 完成 100 次配置转换，并检查新增设备失败后仍可继续配置。
- Windows Release 的 --flexikey-ui-smoke 通过 11 项生产回调：选择、设备开关、重命名、绑定编辑、配置增删和重新加载。界面草稿立即变化，最终 XML 重新读取一致；本次最大同步回调耗时为 **0.036 ms**。
- 状态同步和设置窗口初始化检查通过。

窗口测试使用独立临时目录，结束后删除该目录；测试绑定保持禁用，不连接硬件工作线程。该测试测量生产回调和持久化闭环，物理键鼠命中测试及厂商程序并行运行的长期观察另行验收。

详细日志位于本机忽略目录 target/validation/input-routing/。

## Vulkan 页面合成对照

原生 Skia/Vulkan 路径已经在 AMD 610M 上执行。最初的 22 次页面转换、窗口恢复和空闲提交检查通过，但 **37.48 ms** 的最大提交间隔超过 **33.34 ms** 门槛；散热页首次绘制约 **32.08 ms**。这份失败测量保存在 graphics/results.json。

渲染器的 itemrenderer.rs / visit_opacity 对整页透明度调用 save_layer_alpha。工作区淡入淡出改为覆盖背景色矩形，页面直接绘入原目标，过渡时长和曲线保持原值。

修改后的同一测试测得最大提交间隔 **30.43 ms**、P95 **4.38 ms**，超过 33 ms 的间隔为 0；散热页首次绘制为 **26.67 ms**。该轮通过 33.34 ms 门槛，记录位于 overlay-graphics/results.json。单次对照有运行波动，后续继续保留首次进入的单独测量。

默认 Release 的 --graphics-smoke 支持通过 RAM_GRAPHICS_SMOKE_SNAPSHOT 指定最终渲染快照路径；性能采样在快照生成之前结束。

最终构建复测：最大提交间隔 **30.61 ms**，P95 **4.30 ms**，散热页首次绘制 **25.04 ms**，22 次转换和 33.34 ms 门槛通过。窗口缩放、最小化恢复及一秒空闲零提交检查通过。当轮最终快照由 Slint take_snapshot() 在 CPU 上重新绘制，只验证静态布局，不能验证 Vulkan 目标图像；记录在 final-graphics/。屏幕遮挡采集未用于此结论。后续 GPU 直接读回的检查见 rendering.md。
